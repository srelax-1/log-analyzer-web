# log-analyzer-web
A client-side web application for rapid log analysis. Upload any log file to immediately generate visual charts of log level frequencies and view a breakdown of recurring error patterns.

## Features

- [ ] Upload log files (supports .txt and .logs file extensions ).
- [ ] Identify frequently occurring errors.
- [ ] Filter log by Level
- [ ] Search logs
- [ ] Date-range filtering

## Technologies
- Go

## Running the application

```go
go run main.go
```
